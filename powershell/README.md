# PowerShell emulator (Scratch)

A PowerShell-style terminal that runs inside a Scratch project, generated by `build.mjs` through
`../turbowarp-remote/twctl.mjs`. Open the exported `powershell.sb3` in TurboWarp or Scratch and press the green flag.

- Terminal text is drawn with the pen: one costume per character, stamped on a 60 x 16 grid (8 x 15 px cells).
- Input uses Scratch's ask box with a `PS C:\Users\user>` prompt.
- A virtual filesystem (paths, files, folders, `.`/`..`/`~`, relative and absolute paths) lives in Scratch lists.

## Commands

| command (aliases) | notes |
|---|---|
| `Get-ChildItem` (`ls` `dir` `gci`) `[path]` | Mode / Length / Name table |
| `Set-Location` (`cd` `sl`) `<path>` | `..`, `~`, absolute and relative paths |
| `Get-Location` (`pwd`) | |
| `New-Item` (`ni`) `<name> [-ItemType Directory]`, `mkdir` (`md`) | |
| `Remove-Item` (`rm` `del` `ri` `rmdir`) `<path>` | recursive; `-flags` are ignored |
| `Get-Content` (`cat` `type` `gc`) `<file>` | multi-line |
| `Set-Content` (`sc`) / `Add-Content` (`ac`) `<file> <text>` | |
| `Write-Host` (`echo`) `<text> [> file] [>> file]` | quotes and `$var` expansion, redirection |
| `$name = value`, `$name` | variables; `$PWD` and `$HOME` built in |
| `Get-Date`, `whoami`, `hostname`, `Clear-Host` (`cls`), `help`, `exit` | |

Command names are case-insensitive. Unknown commands print PowerShell's "not recognized" error.
Not included: pipes, quoting with spaces in paths, arithmetic, history / tab completion.

## Build

```bash
open -n ../turbowarp-remote/TurboWarpRemote.app
node build.mjs                                            # system monospace font
FONT_FILE=/path/to/font.ttf FONT_SIZE=14 node build.mjs  # custom font
```

`FONT_FILE` takes a TrueType (`.ttf`) font. `ttf.mjs` is a small dependency-free outline reader: every character
is converted to an SVG path and baked into the project, so the result looks the same on any machine.
CFF `.otf` and `.woff` files are not supported.

`powershell.sb3` is gitignored so a build that embeds a proprietary font (e.g. Consolas) is never committed;
rebuild it locally with your own font.

## Gotchas found while building

- List fields in blocks need `variableType: 'list'` (like broadcast fields in `../invaders`), otherwise the VM creates
  stray scalar variables and the editor's workspace rejects the scripts.
- That rejection makes the editor throw "Tried to glow stack on block that does not exist" on every frame, which
  stops the stage from ever being redrawn even though the project keeps running.
- Keep the editor on the Stage while adding blocks (`select Stage`), and select the sprite only after exporting.
- The ask box covers the bottom of the stage, so only 16 rows of text are used.

## Testing without typing

`runtime.emit('ANSWER', 'ls')` answers the pending ask box, so commands can be driven from `twctl eval` and the
`Screen` list read back. `test.mjs` does exactly that:

```bash
node test.mjs '["cls","mkdir demo","cd demo","echo hi > a.txt","ls","cat a.txt"]'
```
